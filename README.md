# T31K Binder

Биндер фраз для Windows: фраза по сочетанию клавиш вставляется в активное окно,
будто вы нажали **Ctrl + V**. Окно открывается и прячется своим сочетанием,
висит поверх игры и становится полупрозрачным, как оверлей.

Автор — **T31K**.

![Иконка](build/appicon.png)

## Возможности

- **Глобальные сочетания** работают в любой программе и в игре (в оконном режиме
  или полноэкранном без рамки).
- **Вставка как Ctrl + V**: фраза попадает в буфер, нажимается Ctrl + V, потом
  в буфер возвращается то, что было там раньше. Для окон, где Ctrl + V не
  срабатывает, есть посимвольный ввод.
- **Переназначение одним нажатием**: щёлкните по сочетанию у фразы и нажмите
  новое, например Alt + 1 сменится на Alt + 2. Если сочетание уже стоит на
  другой фразе, оно переедет на эту.
- **Оверлей**: окно поверх всех, прозрачность настраивается ползунком,
  при показе окно не забирает фокус у игры.
- **Enter после вставки**, чтобы фраза сразу отправлялась (по желанию).
- **Автообновление** из релизов этого репозитория.

## Установка

Скачайте `T31K-Binder.exe` из [последнего релиза](https://github.com/tthreeonek/t31k-binder/releases/latest)
и запустите. Нужен WebView2 (в Windows 10/11 он уже есть).

| Действие | Сочетание по умолчанию |
|---|---|
| Открыть / скрыть биндер | Ctrl + Alt + B |
| Фразы 1–5 | Alt + 1 … Alt + 5 |

Фразы и настройки хранятся в `%APPDATA%\T31K Binder\config.json`.

Если игра запущена от администратора, биндер тоже запускайте от администратора,
иначе Windows не пропустит вставку.

## Сборка

Нужны Go 1.25+ и [Wails v2](https://wails.io) (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`).
Интерфейс — обычные HTML/CSS/JS в `frontend/dist`, npm не нужен.

```sh
wails build -platform windows/amd64 -ldflags "-s -w"
```

Готовый файл — `build/bin/T31K Binder.exe`.

## Выпуск версии

```sh
./scripts/release.sh 1.0.1 "Что изменилось"
```

Скрипт поднимает версию, собирает exe, делает коммит и тег, пушит и создаёт
релиз на GitHub (нужен `gh`, авторизованный через `gh auth login`). Установленные
биндеры увидят релиз и предложат обновиться.
